## 2. 지금 모바일에서 불편한 점 (코드로 확인한 것)

### 공통
- C1. 모바일 상단 띠에 항상 `관리자`만 보여 지금 어느 화면인지 알 수 없다. ☰ 버튼이 36px로 작다.
- C2. 담당 계정은 메뉴가 2~4개뿐인데도 화면을 옮길 때마다 ☰ → 메뉴 → 선택 3번을 눌러야 한다.
- C3. 팝업(Dialog)이 모바일에서도 가운데 뜬 작은 창이라, 긴 폼은 끝까지 스크롤해야 저장 버튼이 나온다.
  저장 실패 문구도 맨 아래에 있어 안 보인다.
- C4. 아이콘 버튼이 28~36px(`h-7 w-7`, `size-9`)로 손가락 기준(44px)보다 작다.

### 작품 관리
- P1. 목록이 6칸 표라 360px에서 가로로 넘치고, 수정 버튼이 오른쪽 끝에 숨어 가로 스크롤해야 누를 수 있다.
- P2. 바깥 여백 `p-6`이 좁은 화면에서 공간을 많이 쓴다.
- P3. 수정 팝업이 기본정보→소개글→이미지 5종→공개→시민참여→신청서 질문까지 한 줄로 이어져,
  담당자가 가장 자주 고치는 **접수 상태·신청서 질문이 맨 아래**에 있다.
- P4. 신청서 질문 카드가 전부 펼쳐져 있어 질문 7~8개면 스크롤이 매우 길다. 순서 화살표·삭제 버튼이 28px.
  삭제는 확인 없이 바로 지워진다(오터치 위험).

### 연습일지 목록
- L1. 팀 버튼이 여러 줄로 접혀 목록이 아래로 밀린다.
- L2. `연습일지 쓰기` 버튼이 맨 위에만 있어 목록을 내리면 사라진다.
- L3. 카드에 내용 미리보기가 없어 열어봐야 무슨 연습인지 안다.

### 연습일지 보기
- V1. 버튼 3개(인쇄·고치기·삭제)가 위에 줄지어 있고, 읽고 난 뒤 아래에서는 고치기로 갈 수 없다.
- V2. 정보 표 머리칸이 `w-28`(112px)로 고정돼 좁은 화면에서 값 칸이 좁다.
- V3. 사진을 누르면 새 탭으로 원본이 열려 일지로 돌아오기 번거롭다.
- V4. 이전·다음 연습으로 넘기는 방법이 없어 매번 목록으로 돌아가야 한다.
- V5. 댓글 지우기 버튼이 28px.

### 연습일지 쓰기
- W1. 아래 고정 띠에서 오류 문구·취소·저장이 한 줄에 몰려, 문구가 길면 버튼이 찌그러진다.
  아이폰 홈 막대(safe-area) 여백이 없다.
- W2. 시간 입력 두 칸이 좁게 붙고, 날짜와 시간이 한 덩어리로 쌓인다.
- W3. 출석 칸 높이가 40px 안팎이라 연습실에서 빠르게 누르기에 작다.
- W4. 임시 저장이 되고 있다는 표시가 없어 사용자가 불안해한다.

### 연습일지 설정
- T1. 팀 카드의 수정·삭제 아이콘이 36px로 붙어 있어 삭제 오터치 위험.
- T2. 팀원 이름 배지가 전부 펼쳐져 카드가 길다(팀원 10명 × 4팀).
- T3. 팀 추가·수정 팝업과 계정 팝업이 작은 창(C3과 같음).
- T4. 계정 목록에서 아이디 칸이 `w-44`(176px) 고정이라 360px에서 이름이 잘린다.

## 3. 수정 계획

### 3-1. 공통 부품 (새 파일 2개 + 사이드바 수정)

**(가) `components/admin/mobile-sheet.ts` — 모바일 전체 화면 팝업 클래스 묶음**
공용 Dialog는 건드리지 않고, 대상 팝업 3개(작품·팀·계정)에만 덧붙이는 className 상수.
- `sm` 미만: `inset-0` 전체 화면, 모서리·테두리 없음, 세로 flex(머리글 고정 / 본문 스크롤 / 아래 버튼 고정)
- `sm` 이상: 지금과 같은 가운데 창
- 아래 버튼 줄은 `pb-[env(safe-area-inset-bottom)]`, 버튼은 모바일에서 반반 폭·높이 44px
- 저장 실패 문구는 아래 버튼 줄 바로 위에 붙여 항상 보이게

**(나) 모바일 상단 띠 개선 (`admin-sidebar.tsx`)**
- `관리자` 대신 **지금 화면 이름**(메뉴 label)을 보여준다. ☰ 버튼 44px.
- 메뉴가 열려 있는 동안 배경 스크롤 잠금.

**(다) `components/admin/mobile-tab-bar.tsx` — 아래 탭 막대 (모바일 전용, 담당·연습일지 계정만)**
- 메뉴가 2~5개인 group·rehearsal 계정에 한해 화면 아래에 아이콘+짧은 이름 탭을 둔다
  (예: 작품 / 신청자 / 연습일지 / 설정). 총괄 관리자(메뉴 15개)는 지금처럼 ☰만.
- 메뉴가 1개뿐인 팀원·수강생 계정에는 띄우지 않는다.
- **쓰기·고치기 화면에서는 숨긴다**(아래 저장 띠와 겹치므로).
- 탭 막대가 있는 화면은 본문 아래에 그만큼 여백을 준다.

### 3-2. 작품 관리
- P1 → `md` 미만에서는 표 대신 **카드 목록**(제목, 유형·공개 배지, 접수 상태 배지, 공연장, 큰 `수정` 버튼).
  `md` 이상은 지금 표 그대로.
- P2 → `p-4 sm:p-6 lg:p-8`.
- P3 → 팝업을 모바일 전체 화면으로 바꾸고, 머리글 아래에 **구역 바로가기 칩**
  (`기본 정보 · 소개 · 이미지 · 신청 접수 · 신청서 질문`)을 고정. 누르면 그 구역으로 스크롤.
  구역 순서·PC 모양은 바꾸지 않는다(구역마다 `id`와 소제목만 추가).
- P4 → 질문 카드를 **접힌 요약 줄**(`3. 질문 문구… · 예/아니오 · 필수`)로 보여주고 누르면 펼친다.
  새로 추가한 질문과 조건이 깨진 질문은 펼친 채로. 화살표·삭제 버튼 40px, 삭제는 확인 후.
  (PC에서도 같은 접기 방식 적용 — 질문이 많을 때 PC도 편해진다)

### 3-3. 연습일지 목록
- L1 → 팀 버튼을 **한 줄 가로 스크롤**로(모바일만). 고른 팀이 보이도록 자동 스크롤.
- L2 → 모바일에서 `연습일지 쓰기`를 **오른쪽 아래 떠 있는 버튼**으로(탭 막대 위). PC는 지금 위치.
- L3 → 카드에 내용 2줄 미리보기(`line-clamp-2`)와 오른쪽 `>` 표시.

### 3-4. 연습일지 보기
- V1 → 모바일에서는 위 버튼 줄을 아이콘+짧은 글(`PDF` `고치기` `삭제`)로 줄이고,
  문서 아래에도 `고치기` 버튼을 한 번 더 둔다.
- V2 → 머리칸 `w-20 sm:w-28`, 모바일 좌우 여백 축소(인쇄 모양은 그대로).
- V3 → 사진을 누르면 기존 `components/shared/image-lightbox.tsx`로 화면 안에서 크게 본다.
- V4 → 문서 아래에 `← 이전 연습 / 다음 연습 →` 버튼(같은 팀 일지 목록을 한 번 읽어 계산).
- V5 → 댓글 지우기 버튼 40px.

### 3-5. 연습일지 쓰기
- W1 → 아래 띠를 두 줄로: 윗줄 오류 문구(있을 때만), 아랫줄 `취소`(1) : `저장`(2) 비율의 큰 버튼. safe-area 여백.
- W2 → 날짜 한 줄, 시작·끝 시간은 `grid-cols-2`로 같은 폭.
- W3 → 출석 칸 최소 높이 48px.
- W4 → 아래 띠 위에 `이 기기에 임시 저장됨` 작은 표시(저장 시점에만 잠깐).

### 3-6. 연습일지 설정
- T1 → 모바일에서 수정은 글자 있는 버튼으로, 삭제는 카드 맨 아래 작은 글자 버튼으로 떨어뜨린다.

- T4 → 계정 줄을 모바일에서 2줄(아이디 / 이름·상태)로, 비밀번호 초기화는 글자 있는 버튼으로.

## 5. 검증

- `npx tsc --noEmit -p .` / `npm run lint` / `npm run build`
- 로컬 백엔드 + `npx next start -p 3100 -H 127.0.0.1`로 띄우고, 로컬 DB 임시 계정으로 로그인해
  폭 390px(아이폰)·360px(안드로이드 소형)·1280px(PC 회귀)에서 화면을 직접 본다.
- 확인 항목: 가로 넘침 없음, 저장 버튼이 항상 보임, 누르는 곳 44px 이상, 입력 칸 글자 16px 이상(iOS 자동 확대 방지),
  인쇄·PDF 모양이 그대로인지, PC 화면이 그대로인지.
- 임시 계정·데이터는 확인 뒤 지운다. 커밋은 로컬까지만 하고 **push는 사용자 승인 뒤**.

## 6. 지켜야 할 기존 결정 (핸드오프)

- 연습일지 첨부 파일 기능을 다시 넣지 않는다. 연습일지 입구를 상단 띠에 넣지 않는다.
